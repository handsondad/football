# ⚽ 足球奇遇记

一套写给孩子与家长的互动足球百科与陪练工具箱——从球场上真实有趣的「为什么」出发，把足球规则、脚法奥秘、阵型智慧、传奇故事与科学防伤讲得既好玩又透彻。

---

## ✨ 三种阅读模式，一键自由切换

每个球场问题都支持在页面顶部随时切换视角：

- **👦 亲子模式**：通过「小念 × 爸爸」一问一答和直观小图解，把越位、香蕉球、盲侧跑位、点球心理讲得深入浅出，适合陪孩子一起读、一起聊。
- **🎓 专业模式**：为想多懂一点的家长与校园教练准备的原理解析、观察要点、家庭陪练小游戏与运动防伤提醒。
- **🌗 双层同看**：孩子看故事与动画图解，大人看门道与训练方法，同一个问题各有所获。

## 🚀 本地运行

确保电脑已安装 [Node.js](https://nodejs.org/)（建议 18 及以上版本），在项目目录下运行：

```bash
npm install
npm run dev
```

打开终端显示的本地网址（默认 `http://localhost:5173`），即可开始探索。
