# ⚽ 足球奇遇记

一套写给孩子与家长的互动足球百科与陪练工具箱——从球场上真实有趣的「为什么」出发，把足球规则、脚法奥秘、阵型智慧、传奇故事与科学防伤讲得既好玩又透彻。

---

## ✨ 三种阅读模式，一键自由切换

每个球场问题都支持在页面顶部随时切换视角：

- **👦 亲子模式**：通过「小念 × 爸爸」一问一答和直观小图解，把越位、香蕉球、盲侧跑位、点球心理讲得深入浅出，适合陪孩子一起读、一起聊。
- **🎓 专业模式**：为想多懂一点的家长与校园教练准备的原理解析、观察要点、家庭陪练小游戏与运动防伤提醒。
- **🌗 双层同看**：孩子看故事与动画图解，大人看门道与训练方法，同一个问题各有所获。

---

## 🧭 在这里可以探索什么？

- **📚 21 个足球主题馆 · 111 个球场为什么**
  覆盖球场与球鞋奥秘、最新裁判规则、传停带射与守门技术、阵型战术、热身防伤与营养、运动心理、百年历史与传奇名局、女足与村超文化、球探看球门道及无球跑位单防技巧。
- **🎛️ 互动战术与科学沙盘**
  动手点一点、切换不同瞬间，直观玩懂越位判罚划线、香蕉球与电梯球风洞、阵型攻防转换、接球前抬头扫描盲区、抢圈三角配合与四球门小比赛。
- **📋 分龄陪练游戏 & 成长小助手**
  精选 16 套带球场示意图的分龄足球游戏卡，并附带青少年体能参考计算器与生长期（身高猛长期）护膝、护脚跟温馨提醒。
- **📖 足球中英双语小词典**
  把解说员嘴里的「倒三角」「肋部空间」「高位逼抢」「门卫」等 58 个高频词，翻译成看球时一眼就能认出来的赛场画面。
- **📍 京北绿茵地图 & 踢球成长指南**
  汇总回龙观与京北周边实用球场信息，以及青少年常见赛制、年龄段球场规格与校园足球常识。

## 🚀 本地运行

确保电脑已安装 [Node.js](https://nodejs.org/)（建议 18 及以上版本），在项目目录下运行：

```bash
npm install
npm run dev
```

打开终端显示的本地网址（默认 `http://localhost:5173`），即可开始探索。
