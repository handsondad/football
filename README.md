# ⚽ 足球奇遇记 · 可扩展双层足球知识引擎

> **设计理念**：同一个足球问题，既要让孩子看得津津有味建立直觉，更要让爸爸学得系统专业、掌握堪比亚足联/欧足联持证青训教练与球探的底层认知。
> 因此全站采用 **「同题双层（Dual-Layer Pedagogy）+ 插件化零侵入扩容架构」**——支持一键在 **「🌗 双层同看 / 🎓 仅看专业深潜内参 / 👦 仅看亲子问答」** 三种视角间自由切换。

## 二、如何持续无限扩容（插件化架构说明）

本仓库通过 `src/content/registry.ts` 的 `import.meta.glob('./domains/*/domain.ts')` 实现**零侵入自动发现**：

1. **新增第 10、11 个全新知识领域**（无需修改路由或任何 React 页面组件）：
   ```bash
   npm run new-content -- domain 10-set-pieces "定位球攻防工程"
   ```
   命令会自动在 `src/content/domains/10-set-pieces/domain.ts` 生成标准模块，保存后首页网格、分类页、跨层搜索与知识图谱自动生效。
2. **新增双层课题 / 标准教案 / 专业词条**：
   - 生成课题骨架：`npm run new-content -- article tactics-board pressing-trap "边线压迫陷阱怎么设？"`
   - 新增教案：往 `src/content/drills/drills.ts` 追加对象并填入 `drillIds` 即可与文章双向互链
   - 新增词条：往 `src/content/lexicon/terms.ts` 追加对象并填入 `lexiconIds` 即可双向互链
3. **运行全量一致性校验**（检查追问链衔接、ProDeepDive 结构完整性、教案/词典/35份文献引用闭环）：
   ```bash
   npm run typecheck
   npm run check
   npm run build
   ```
